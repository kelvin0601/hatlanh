## Important
Except for the clean high-resolution Hero, the JPG images were extracted from an AI-generated **asset-board reference** (not from UI mockup screenshots). They contain no UI controls or overlay text, but are **small, low-resolution visual placeholders** and are NOT production-ready. Some source images are stylized/AI-generated and may not depict the actual product or farm. Replace with full-resolution original photography/generation before launch. Do not claim these show real ingredients, packaging, sourcing or certifications.

Design system: Forest #25452F, Cream #F8F4EA; use mobile-first layout and real product photography for cards.
